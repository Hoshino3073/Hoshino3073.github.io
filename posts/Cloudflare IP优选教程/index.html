Cloudflare IP优选教程

  • 2026-07-06
  • 作者 Yagi Chirishio
  • ~1.67K 字

前言

利用 Cloudflare 的“IP 优选”功能，可以为您的网站选择延迟最低的节点，大幅提升国内访问速度。

准备工作

  • 一个已托管到 Cloudflare 的域名（例如 example.com）。
  • 已开通 自定义主机名 功能的 Cloudflare 账号。

第一步：获取优选域名或优选 IP

您有两种选择，根据自身情况任选其一即可。

方案一：使用优选域名

  1. 访问 CloudFlare 优选域名。
  2. 页面会列出多个域名及其延迟数据，选择对您运营商（电信/联通/移动）延迟最低的一个；如果不确定，直接选择列表中的第一个。
  3. 记录下该域名的值（例如 cdn-xxx.cf.090227.xyz）
    这里推荐几个好用的，visa中国官网，美国FBI官网，乌克兰政府官网

方案二：使用优选 IP

  1. 前往 CloudflareSpeedTest 下载适合您系统的工具。
  2. 按照项目 README 的说明运行测速，工具会自动筛选出速度最快且延迟最低的 IP 地址。
  3. 记录下该 IP 地址（IPv4 或 IPv6，视您的网络支持而定）。

第二步：将优选结果接入您自己的域名

注意：以下操作均在 Cloudflare 仪表盘的 DNS 设置中进行，所有记录均不要开启代理（即保持小黄云为灰色状态）。

如果使用优选域名

  • 添加一条 CNAME 记录：
    • 名称：cdn（或其他您喜欢的子域名，例如 cdn.example.com）
    • 目标：填写第一步中获取的优选域名
    • 代理状态：关闭（灰色云朵）

如果使用优选 IP

  • 添加一条 A 记录（IPv4）或 AAAA 记录（IPv6）：
    • 名称：cdn（同样可自定义）
    • IP 地址：填写第一步中获取的优选 IP
    • 代理状态：关闭（灰色云朵）

这样，您就拥有了一个指向最优节点的“中间域名”（例如 cdn.example.com）。

第三步：让 Cloudflare 使用优选结果（自定义主机名配置）

假设您的网站源服务器 IP 是 1.1.1.1，我们需要通过自定义主机名功能，将您真正的访问域名（如 www.example.com）指向这个优选节点。

  1. 设置基础代理域名
    在 DNS 中添加一条 A 记录：

    • 名称：123（或任意，这里仅作示例）
    • 内容：1.1.1.1（您的源站 IP）
    • 代理状态：开启（橙色云朵）
      这条记录只是为了提供一个开启代理的“源站”占位，之后自定义主机名会用到它。

  2. 将您想用来访问的域名指向优选节点
    添加一条 CNAME 记录：

    • 名称：www（或您想使用的子域）
    • 目标：第二步中创建的 cdn.example.com
    • 代理状态：关闭（灰色云朵）

  3. 配置自定义主机名

    • 进入 Cloudflare 控制台，在对应域名的菜单中找到 自定义主机名（Custom Hostnames）。
    • 在 回退源（Fallback Origin） 处，随便填写一个已开启代理的域名（例如上面创建的 123.example.com），它仅作为占位，不需要能实际访问。
    • 点击“添加自定义主机名”，填写：
      • 主机名：www.example.com（外部看到的域名）
      • 源服务器：123.example.com（未经优选的域名）
    • 验证方式选择 HTTP 验证（Cloudflare 会自动完成验证；如果选 TXT 则需要手动添加解析记录）。

  4. 等待几分钟，验证通过后，当您访问 www.example.com 时，流量就会经过您优选出的节点，速度得到优化。

验证与生效

  • 您可以使用 ping 或 dig 命令检查 www.example.com 解析是否指向了您优选出的 IP/域名。
  • 也可通过在线测速工具对比前后的延迟变化。

注意事项

  • 优选 IP 会因网络环境和时间而变化，建议定期重新测速并更新 DNS 记录。
  • 自定义主机名功能需要绑定信用卡，但无需付费，free计划的用户可免费创建100个。
  • 本文中的示例域名和 IP 请替换为您自己的真实信息。
